## 03 / How I work

| | |
|---|---|
| **Evaluate before believing** | Chance-level baselines, paired comparisons, test sets committed before scoring, pre-registered analysis plans |
| **Build the whole thing** | Models, training loops, serving, auth, rate limits, CI, so I know where each failure actually comes from |
| **State the limits** | Every repo says what it does not do. Claims are matched to evidence, not to what sounds good |
| **Reproduce or it didn't happen** | Bit-exact resume, fresh-clone CI replay, hashed artifacts and manifests |
