# Aarav Khanal

**AI/ML and full-stack developer building practical software with applied AI.**

I enjoy taking a rough idea, working through the hard parts, and turning it into a product people can use. Lately I’ve been exploring video understanding, computer vision, and multi-agent systems.

## What I’m building

### [UnderstandVideo AI](https://github.com/Aaravkhanal/understandvideo-ai)

A workspace for exploring videos with searchable transcripts, scene navigation, and timestamp-linked answers. [Try the live app](https://understandvideo-ai.onrender.com).

### [ProjectMind AI](https://github.com/Aaravkhanal/ProjectMind-AI)

An AI-assisted code review workspace that brings together parallel reviewers, project context, and model choice.

### [FrameFlow AI](https://github.com/Aaravkhanal/Frameflow-ai)

Turns screenshots, Figma designs, and website references into frontend starting points, with multiple models helping check the result.

### [Nexora AI](https://github.com/Aaravkhanal/NEXORA-AI)

A company research tool that gathers findings into a dashboard and lets you ask follow-up questions.

### [Jubidate AI](https://github.com/Aaravkhanal/Jubidate_ai)

A strategic reasoning workspace where AI agents debate different sides of a question and produce a considered summary.

### [VIBE-SHIELD](https://github.com/Aaravkhanal/VIBE-SHIELD)

An autonomous security and quality scanner for AI-built apps, covering checks from code quality to prompt-injection risks.
